The great Golden Age mod remade to improve its performance with Holy Empire mechanics, formable countries, and optimized for multiplayer.

(IMPORTANT)

If you're going to host a multiplayer game, don't run the normal mod; instead, run Golden Age_Hosted_bug_Lobby_Fixed, and only that one, to fix a crash bug in lobbies. (It's not 100% necessary, but it provides more stability in lobbies to prevent the typical crash when people type in the chat; it doesn't change the checksum)
